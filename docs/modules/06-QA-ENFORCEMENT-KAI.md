const gpsDistanceM = (a, b) => {
  const R = 6371000; // Earth's mean radius in meters
  const r = x => x * Math.PI / 180;
  const dLat = r(b[0] - a[0]);

When the magistrate convenes the hearing, both the prosecution and defense receive the unedited report. This total transparency dismantles false brutality claims, verifies reasonable force, and insulates the State from civil liability.

### Q15: How do hardcoded fine ranges (e.g., ₦50k–₦250k for drainage dumping) and the 72-hour community service cap prevent magisterial sentencing abuses, and how are community service hours digitally tracked and closed?

#### Historical Judicial Inconsistency
In legacy mobile courts, magistrates wielded unbounded discretionary sentencing power. For the exact same offense of dumping refuse in a gutter, one magistrate in Oshodi would impose a ₦2,000 token fine, while another magistrate in Victoria Island would impose a catastrophic ₦1,000,000 fine or six months of hard labor. Furthermore, corrupt court clerks routinely accepted informal cash settlements, recording defendants as "Discharged" on paper while pocketing the money.

#### Technical Resolution: Hardcoded Statutory Schedules
Module 06 hardcodes the statutory sentencing boundaries directly into the application state:
```javascript
const KAI_FINES = {
  'Street trading on road/median': [20000, 100000],
  'Dumping refuse in drainage': [50000, 250000],
  'Failure to bag waste': [10000, 50000],
  'Illegal cart-pusher dumping': [20000, 100000]
};

const COMMUNITY_SERVICE_MAX_HOURS = 72;

const sentenceValid = (s, fineRange) => 
  s.kind === 'Fine' 
    ? s.amount >= fineRange[0] && s.amount <= fineRange[1]
    : s.kind === 'Community service' 
      ? s.hours > 0 && s.hours <= COMMUNITY_SERVICE_MAX_HOURS 
      : s.kind === 'Discharged';
```

#### Operational Workflow & Community Service Tracking
1. **Sentence Input Validation:** If a magistrate attempts to record a fine of ₦300,000 for drainage dumping (where the maximum statutory limit is ₦250,000), or attempts to sentence a defendant to 100 hours of community service (violating the 72-hour statutory ceiling), the workspace rejects the entry:
   `"Fine must be within the schedule / Community service must be 1–72 hours."`
2. **Digital Tracking of Community Service:** When a sentence of community service is entered (e.g., 24 hours of median street sweeping over 3 days):
   * The defendant is assigned to an authorized LAWMA Highway Sweeping Supervisor.
   * The supervisor logs daily hours on their mobile terminal using the defendant's biometric fingerprint scan at arrival and departure.
3. **Closing the Case (`kai-close`):** The system prevents a case from moving to `Closed` status until the supervisor uploads the certified completion sheet or the banking switch confirms the TSA fine payment receipt reference:
   ```javascript
   if (c.stage === 'Closed') kaiCloseYard(c);
   ```
   Only when the case is verifiably closed in the court docket does the system grant clearance for the vehicle or property to be released.
